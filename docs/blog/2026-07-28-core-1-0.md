IndustrialComm 生态的第一个生产级 NuGet 包 **Mokode.IndustrialComm.Core 1.0** 现已就绪。

它提供二进制编解码、工业常用校验、帧缓冲、传输抽象、`CommResult` 错误模型、超时/重试与诊断接口，为后续 Modbus 等协议包铺路。

安装：

```bash
dotnet add package Mokode.IndustrialComm.Core
```
